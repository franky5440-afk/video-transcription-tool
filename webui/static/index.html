          還沒有偵測到你電腦上的處理服務

          這個公開頁面只是操作介面；下載、轉錄與翻譯全部在你自己的電腦上執行， 檔案不會上傳到任何伺服器。請先在電腦上把後端跑起來：

          1. 安裝 Python 3 與 ffmpeg
          2. git clone https://github.com/franky5440-afk/video-transcription-tool.git
          3. pip install -r requirements.txt
          4. python cli.py serve

          啟動之後這個分頁會自動連上（每 5 秒重試一次）。Linux 使用者也可以直接使用 AppImage。

          參考速度：轉錄耗時大約是影片長度的一半——一支 8 分鐘的影片約 4 分鐘。 中文影片會跳過翻譯步驟，所以更快；燒字幕進影片則會再多花一些時間。 實際時間依機器效能而異，請耐心等候。
